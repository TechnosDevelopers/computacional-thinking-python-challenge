# Guia Técnico e Informativo - Computational Thinking Using Python (Sprint 1)

## 1. Título e Descrição
- **Nome do Projeto:** Sistema de Automação e Apoio à Decisão - Turma do Bem
- **Objetivo:** Desenvolver uma solução inicial em Python estruturada com menu de opções e funcionalidades essenciais baseadas nas regras de negócio da Turma do Bem, unindo lógica de programação estruturada, tratamento de dados e documentação técnica.

## 2. Tecnologias Utilizadas
- **Python 3.x:** Linguagem de programação principal.
- **Estruturas de Controle e Dados:** Variáveis, operadores, estruturas de decisão, repetição e manipulação de I/O (`f-strings`).
